# sci-phil.ai.studio — Canlı Senkron + Vitrin

Bu paket, emrepelit7337.blogspot.com üzerindeki **yalnızca orijinal Türkçe** yazıları süzgeçten geçmiş halde gösterir.

## Vitrin
Ana sayfanın en üstünde **en yeni yazı** büyük kart olarak öne çıkar:
**Evren Her Zaman Tekil Bir Olguydu ve İlelebet de Öyle Kalacak** (13 Ekim 2026)

Yeni yazı eklendiğinde otomatik olarak vitrin olur.

## Yayınlama (alan adı değişmeden)

1. Zip'i aç.
2. Vercel'de proje oluştur veya mevcut projeyi güncelle.
3. Deploy sonrası **Settings → Domains**'ten `sci-phil.ai.studio` domain'ini bağla.

Yerel:
```bash
npm install
npm run dev
```
