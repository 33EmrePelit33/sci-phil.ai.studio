OpenAPI 3.0 / REST API

Science & Philosophy Public REST API

Mobil uygulamalar, veri araştırmaları ve otomasyonlar için salt okunur yüksek performanslı JSON API arayüzü.

← Ana Sayfa Analytics Paneli openapi.json Şeması ↗ 📦 Külliyat Yedeği İndir (JSON)
GET /api/v1/articles
Katalogdaki makaleleri sayfalı, dil ve kategori filtreli olarak döndürür. Parametreler: page, limit, lang, category, cluster, q.
GET /api/v1/articles?lang=tr&limit=10
GET /api/v1/articles/{slug}
Belirtilen makalenin tam metnini, diyalektik üçlüsünü (iddia, karşı iddia, neyin kanıtı olmadığı) ve bağlı konu kümesini döndürür.
GET /api/v1/articles/zamanin-simulasyon-yapisi-ve-noronal-zaman-algisi-3395198863934648239
GET /api/v1/clusters
Site bünyesindeki 5 ana SEO ve düşünsel Konu Kümesini (Topic Clusters), pillar makalelerini ve anahtar kelimelerini listeler.
GET /api/v1/clusters
GET /api/v1/search
Başlık, özet ve kavramsal anahtar kelimelerde anlık arama yapar.
GET /api/v1/search?q=bilinc
GET /api/v1/ai/forecast
Zaman serisi projeksiyon modeli ile indekslenme oranı, organik gösterim tahmini ve içerik derinleştirme önerilerini sunar.
GET /api/v1/ai/forecast
GET /api/v1/automations/digest
Search Console ve Analytics verilerinin haftalık zamanlanmış otomatik özet raporu.
GET /api/v1/automations/digest
GET /api/v1/export/backup
Tüm makale külliyatını, katalog yapısını ve site haritası metaverilerini tek tıkla indirilebilir JSON formatında dışa aktarır.
GET /api/v1/export/backup
